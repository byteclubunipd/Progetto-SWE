# Progetto di Ingegneria del Software
Repository del gruppo ByteClub appartenente al primo lotto del corso di Ingegneria del Software A.A. 2026-27, CdL triennale in Informatica, Università degli Studi di Padova.  

## Contenuti
La repository è organizzata nel seguente modo:

```text
.
├── .github/                                                 Workflow GitHub
│   ├── scripts/                                             Script di build dei documenti e sito web
│   └── workflows/                                           GitHub Actions
├── docs/                                                    Documentazione e sorgenti Typst
│   ├── 1_Diario_di_bordo/                                   
│   ├── 2_Candidatura/                                       
│   │   ├── Documenti_esterni/                               
│   │   ├── Documenti_interni/                               
│   │   ├── Lettera_di_presentazione/                        
│   │   └── Verbali/                                         
│   │       ├── Esterni/                                     
│   │       └── Interni/                                     
│   ├── 5_Templates/                                         Modelli dei documenti
│   └── 6_Output/                                            Replica della struttura con soli PDF
├── test/                                                    Test del sito e del progetto
├── website/                                                 Sorgenti del sito GitHub Pages
│   └── assets/                                              Risorse grafiche del sito
├── README.md                                                
├── Contributing.md                                          Regole per contribuire
└── .gitignore                                               
```

### Consultare le risorse
È possibile consultare l'ultima versione di ogni documento in formato PDF nella cartella [6_Output](docs/6_Output) o tramite il [sito web dedicato.](https://byteclubunipd.github.io/Progetto-SWE/)


La pubblicazione su GitHub Pages parte sia da `main` sia da `develop`. I due branch
aggiornano lo stesso sito: il contenuto online corrisponde all'ultima pubblicazione
completata.
